# Polyizon PropOS

Polyizon PropOS is a multi-tenant property operations platform for property managers, landlords, owners, tenants, finance teams, caretakers and vendors.

## Product direction

- Multi-tenant SaaS architecture
- Operator console for onboarding and managing property-management organizations
- Property, building, unit and owner management
- Tenant CRM and lease lifecycle
- Rent collection, arrears and accounting
- Maintenance, inspections, utilities and vendors
- Owner and tenant portals
- Communications, automations and AI assistance
- Kenya-first payment integration strategy, including M-Pesa

## Current milestone

The repository starts with a polished responsive dashboard prototype that defines the visual system and navigation for the product.

## Stack

- React
- TypeScript
- Vite
- CSS design system
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```
